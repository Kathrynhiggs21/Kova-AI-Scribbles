# KOVA Scribbles Integration

Optional integration module connecting KOVA OS with the independent Scribbles project.

## Scope

This repository may contain Scribbles-specific connector code and automation. It must not duplicate the KOVA control plane, dashboard, assistant, authentication, memory layer, or document engine.

Canonical KOVA architecture and repository roles live in [Kathrynhiggs21/Kova-ai-SYSTEM](https://github.com/Kathrynhiggs21/Kova-ai-SYSTEM). Scribbles product code remains in its own repositories and domain boundary.

## Status

Catalogued but disabled in the KOVA runtime registry. The repository currently contains integration instructions and automation configuration, not a production service.
